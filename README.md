# Sheng Ao 的学术主页

网站：https://aosheng1996.github.io/

## 日常维护

- 姓名、单位、邮箱、学术链接和头像设置：`_config.yml`
- 个人介绍、News、精选论文和学术服务：`_pages/about.md`
- 个人照片：`images/sheng-ao.jpg`
- 论文配图：`images/`
- 顶部导航：`_data/navigation.yml`

目前所有个人学术内容集中在首页。模板附带的示例文章、虚构 CV、示例论文/课程/报告/作品集及其演示文件已移除。

## 本地预览

安装 Ruby 和 Bundler 后，在仓库目录运行：

```sh
bundle install
bundle exec jekyll serve
```

`Gemfile` 管理 Jekyll 依赖；`package.json` 用于需要时重新生成主题 JavaScript。通常更新主页内容不需要重新生成 JavaScript。
